## Decisions of record for this pass

- Residual value ruling (under the controller lens, user-delegated, 2026-10-07): residual value is a terminal cash inflow and belongs to collections. It is a first-class, visible, selectable input (amount and year); it participates in NPV(collections) so the solved payment falls accordingly; the cost side is untouched. It is never netted against costs: netting would understate the true project cost, corrupt the collection-to-cost ratio, and break the figure traceability of the cost model. A residual of zero reproduces current behavior byte for byte.
- Appraisal defaults of record: WACC 8 percent; finance rate 6 percent; reinvestment rate 6 percent. The MIRR rates are explicit and are never silently equated with WACC or with each other. All three are user-adjustable inputs.
- goalMet supersedes the v0.2.0 carried notice: the engine emits `goalMet = achievedIrr !== null && achievedIrr >= targetIrr / 100 - 1e-9` (meets-or-exceeds semantics, so Mode B over-solving reports true). The UI-side goal-check computation is removed; the UI displays the engine flag.
- Ambiguity limitation superseded: with residual value constructible, net vectors with multiple sign changes exist (residual 2,000,000 at year 1 yields three sign changes). The ambiguity warning must now be tested against a real engine result, not a stub.
- Scenario sets of record: base (burn x1.0, escalation shift 0, target shift 0, term shift 0); optimistic (burn x0.9, escalation -1 point, target -2 points, term +1 year); pessimistic (burn x1.1, escalation +1 point, target +2 points, term -1 year). The burn multiplier applies to every cost line's amount; the escalation shift applies to recurring lines only.

## Conventions of record for the new metrics (all derive from the single monthly vector)

- Monthly rate conversions: r = (1 + annual)^(1/12) - 1, identical to the existing convention. The appraisal rates are wacc, financeRate, reinvestmentRate.
- npvAtTarget and npvAtWacc: the net monthly vector discounted end-of-month at the target rate and at the WACC respectively. For any Mode A structure, npvAtTarget is zero within 1e-6 (the solver identity, now pinned directly).
- npvCollectionsAtWacc and npvCostsAtWacc: the inflow and cost sides discounted at WACC; profitabilityIndex = npvCollectionsAtWacc / npvCostsAtWacc, null when npvCostsAtWacc <= 0. Identity of record: npvAtWacc = npvCollectionsAtWacc - npvCostsAtWacc, so profitabilityIndex >= 1 exactly when npvAtWacc >= 0.
- discountedPaybackYears: the same interpolation rule as nominal payback (crossing month m with previous cumulative below zero: (m - 1) + |prev| / net), applied to the discounted net cumulative. At WACC 0 it is identical to the nominal payback. Null when the discounted cumulative never crosses.
- MIRR: on the net monthly vector of length N, PV = sum of negative net flows discounted at the finance rate to month 0 (end-of-month basis); FV = sum of positive net flows compounded at the reinvestment rate to month N; MIRR (annual) = (FV / |PV|)^(12/N) - 1; null when either side is empty.
- Residual value: an inflow at month 12 x year; the vector horizon extends to cover it; it participates in the Mode A solver (payment = (costNpv - balloon x balloonDf - residual x residualDf) / dfSumEsc) and in every metric.
- Mode B (solveTerm): given a payment per period P and the target rate, the minimum whole payment count n with P x sum(escFactor x df) >= costNpv; termYears = n / paymentsPerYear (may be fractional, 9.5 for the anchor case); lastPaymentMonth = start + (n - 1) x spacing; the horizon extends with the solved term. Infeasible (the stream's total discounted value can never reach costNpv) returns null with a surfaced explanation.
- Mode C (evaluate): given P over the configured structure, all metrics computed on the fixed-payment vector; the achieved IRR is verified numerically as always.
- Validation rules (additions to the contract, surfaced, no silent drops): wacc, financeRate, reinvestmentRate each must exceed -100; residual amount must be >= 0; when residual amount > 0, year must be an integer >= 1; a Mode A balloon whose discounted value at the target rate reaches costNpv is an input error (the solved payment would be non-positive).
