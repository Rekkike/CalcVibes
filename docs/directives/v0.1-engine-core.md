## DEFECT-001 (required repair)

The prototype `irrAnnual` brackets over the monthly rate interval [-0.9999, 10]. At the lower bound, `Math.pow(1 + rM, i + 1)` underflows toward zero for long vectors, so `npvMonthly(-0.9999, flows)` evaluates to a non-finite value (Infinity or NaN). The sign test `fLo * fMid < 0` then never holds, and the bisection marches its lower bound up to the upper bound, returning `Math.pow(11, 12) - 1 = 3138428376720` as the annual IRR.

Script-verified evidence (baseline scenario CP-2 net-flow vector, 120 months):

- Prototype solver output: 3,138,428,376,720 (annual fraction), i.e. the degenerate bracket collapse value 11^12 - 1.
- NPV at the lower bound: non-finite.
- Repaired solver output on the same vector: 0.120000000000 (annual fraction).

Repair contract for `irrAnnual`:

1. Never evaluate the NPV at a monthly rate below -0.9 or above 6.0.
2. Scan a finite grid over [-0.9, 6.0] to find an adjacent pair of rates where the NPV changes sign; if none exists, return null.
3. Bisect within that bracket to convergence (absolute NPV below 1e-9 or 300 iterations).
4. An all-zero flow vector returns null.
5. Return the annualized rate `Math.pow(1 + rM, 12) - 1`.
