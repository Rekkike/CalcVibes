## Decisions of record for this pass

- Blank start (user decision, 2026-10-07): the application opens on an empty new project, never a pre-filled sample. Project Alpha exists only behind an explicit "Load demo project" action, visibly labeled as a demo.
- Engine-only arithmetic: `web/src` contains no financial computation. Every figure the user sees comes from `computeModel`. The only numeric transformation permitted in the UI layer is the display helper's rounding and number or currency formatting.
- Validation UX: the UI calls `validateInputs` live on every input change and surfaces issues visibly, next to the offending fields and in an issues summary. Invalid input never silently drops data, blanks fields, or removes lines; the user's input is preserved while the issue is shown.
- Ambiguity warning: when `irrAmbiguous` is true, the achieved-IRR display carries a visible warning that the net flow has multiple sign changes and the IRR may not be unique.
- Display rounding (spec 4.7): one display helper rounds to the currency's minor unit for presentation only; displayed totals are computed from unrounded engine values.
- Presentation non-negotiables (parity level): charts use zero-based axes for magnitude comparisons; every figure in every section and slide is generated from the live model; the nominal-versus-discounted basis is labeled wherever both appear; number formats are consistent across sections and slides; caveats sit adjacent to the numbers they qualify.
